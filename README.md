# My Application Suite

## Overview
This gui_apps contains two applications designed to enhance productivity and facilitate knowledge sharing.\
Each app serves a unique purpose and offers a set of features to help users manage tasks and engage in learning.

## Applications
1. [Firstapp/ A.K.A Calculator](firstapp/README.md): A Simple Calculator written from scratch.
   [get-apk](https://github.com/Shnku/gui_apps/releases/tag/firstapp-release-1/app-release.apk)
   
3. [Tic-Tac-Toe](tictactoe/README.md): A tictactoe game app with internal Matrix view for better understanding how the app works.
   [get-apk](https://github.com/Shnku/gui_apps/releases/tag/tictactoe-release-1/app-release.apk)
   
4. [Currency Converter App](currency_converter/README.md): Basic application for converting currencies based on realtime currency API.
   [get-apk](https://github.com/Shnku/gui_apps/releases/tag/currency-release-1/app-release.apk)
   
6. [Weather App](weather_app/README.md): A simple weather app based on OpenWeatherAPI with city searching functionality.
   [get-apk](https://github.com/Shnku/gui_apps/releases/tag/weather-release-1/app-release.apk) 
   
8. [Question Answer App](question_app/README.md): An interactive application for asking and answering science-related questions.
   [get-apk](https://github.com/Shnku/gui_apps/releases/tag/question-release-1/app-release.apk) 
   
10. [To-Do App](todo_app/README.md): A simple and intuitive application for managing tasks efficiently.
    [get-apk](https://github.com/Shnku/gui_apps/releases/tag/todo-release-1/app-release.apk) 
    
12. [Arduino Controller Wifi](adruino_control_app/README.md): Basic app to interact/control arduino HIGH/LOW value through wifi connectivity.
    [get-apk](https://github.com/Shnku/gui_apps/releases/tag/arduino-release-1/app-release.apk)
