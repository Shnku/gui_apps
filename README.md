# My Application Suite

## Overview
This repository contains two applications designed to enhance productivity and facilitate knowledge sharing.\
Each app serves a unique purpose and offers a set of features to help users manage tasks and engage in learning.

## Applications

1. [Firstapp/ A.K.A Calculator](firstapp/README.md): A Simple Calculator written from scratch
2. [Tic-Tac-Toe](tictactoe/README.md): A tictactoe game app with internal Matrix view for better understanding how the app works.
3. [Currency Converter App](currency_converter/README.md): Basic application for converting currencies based on realtime currency API.
4. [Weather App](weather_app/README.md): A simple weather app based on OpenWeatherAPI with city searching functionality.
5. [Question Answer App](question_app/README.md): An interactive application for asking and answering science-related questions.
6. [To-Do App](todo_app/README.md): A simple and intuitive application for managing tasks efficiently.
7. [Arduino Controller Wifi](arduino_control_app/README.md): Basic app to interact/control arduino HIGH/LOW value through wifi connectivity.
  

## Conclusion
All applications are designed to enhance user productivity and knowledge sharing. Feel free to explore each app and contribute to their development!
