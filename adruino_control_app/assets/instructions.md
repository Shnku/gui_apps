# Demo Instruction Page

Welcome to the demo application! This page provides instructions on how to use the app effectively.

## Features

- **User Profile**: Customize your profile by adding a profile picture and bio.
- **Dashboard**: View your activity and statistics on the dashboard.
- **Settings**: Adjust your preferences in the settings menu.

## Usage Instructions

### Navigating the App

- Use the bottom navigation bar to switch between different sections of the app.
- Tap on the **Help** icon for assistance.
